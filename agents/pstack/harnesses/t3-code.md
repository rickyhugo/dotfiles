# T3 Code

Discover orchestration capabilities before delegation. When the session exposes
`orchestrator_capabilities` and `delegate_task`, use their current schemas to
select a provider instance, model, options, and workspace.

Apply the role's `t3-code` target as its exact native parameter object, including
nested option fields where required. Validate each configured choice against the
reported capabilities. Use inherited settings when independent selection is not
available and report that limit.

Children may not have named pstack agents. Give them the bundled role file,
absolute skill paths, task scope, base SHA, and required evidence in the brief.
