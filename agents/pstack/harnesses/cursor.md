# Cursor

Use Cursor's exposed Task, question, and plan tools with their current schemas.
Named agents are optional; supply the bundled role file when none is registered.

Apply the configured `cursor` target for each role. Use exact confirmed model
slugs and options, not the upstream vendor defaults or a generated model rule.

Cloud workers, Custom Modes, Automations, Bugbot, and event subscriptions are
available only when this session exposes them. Read only the transcript directory
the session identifies for the authorized workspace.
