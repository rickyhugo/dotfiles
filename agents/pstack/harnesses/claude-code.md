# Claude Code

Use the exposed Agent tool. General work uses its general-purpose agent; use an
exploration agent only if it retains the sources and MCP access the job needs.
Include the bundled role file when no matching native agent is registered.

Apply the role's `claude-code` target only through model/effort controls accepted
by the current schema. A model offered in another harness is not a Claude alias.
If a required control is absent, inherit and report the limitation.

Use native worktree isolation and background completion when offered. Pass paths
in the brief instead of Cursor-only attachment or cloud fields. Use session-scoped
history exposed by the host, not an inferred plugin cache or transcript slug.
